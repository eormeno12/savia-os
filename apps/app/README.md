# apps/app — Savia B2B (pendiente)

Esta carpeta está reservada para la implementación limpia del frontend de
Savia B2B. Todavía no tiene scaffold — se arma cuando arranque la primera
tarea real del rebuild (vía `planner-savia`), no antes.

- **No es** el frontend anterior. Eso vive en [`apps/legacy-app/`](../legacy-app/),
  congelado como referencia — no se le agrega código nuevo.
- Antes de escribir código acá: usar el agente `planner-savia` para convertir
  el requerimiento en criterios de aceptación explícitos.
- Contexto de producto/arquitectura completo: [`docs/product/savia-b2b/`](../../docs/product/savia-b2b/00-overview.md),
  en especial [`14-superficies-de-producto.md`](../../docs/product/savia-b2b/14-superficies-de-producto.md).
