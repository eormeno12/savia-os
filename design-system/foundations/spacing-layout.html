Principios de layout

Una acción primaria por pantalla

Jerarquía clara. Si todo pesa igual, nada pesa. El CTA principal vive sobre superficie oscura.

Split-panel

Un lado oscuro con el formulario directo sobre el fondo; el otro claro que complementa con espacio (statement + journey).

Aire en formularios

gap grande entre bloques, gap chico entre label e input. Un form apretado se siente plano.

Claridad para nuevos

Si una pantalla no se explica sola, mostrá el journey en pasos (stepper vertical) con el paso actual activo.
